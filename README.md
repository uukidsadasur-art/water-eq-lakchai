# ติดตามสถานการณ์ระดับน้ำบ่อ EQ นิคมหลักชัยเมืองยาง

แดชบอร์ดติดตามและแสดงผลข้อมูลระดับน้ำบ่อ EQ แบบ Real-time เชื่อมต่อโดยตรงกับ Google Sheet พร้อมระบบรักษาความปลอดภัยด้วยรหัสผ่าน

## ✨ ฟังก์ชันเด่น
1. **การแสดงผลตามภาพต้นแบบ:** 
   - 4 การ์ดสรุป KPI (ระดับบ่อ EQ ล่าสุด, การเปลี่ยนแปลง, ช่วงเวลาติดตาม, อัตราการลดลงเฉลี่ย)
   - กราฟเส้นแนวโน้ม (Chart.js) พร้อมป้ายแสดงตัวเลขกำกับทุกจุดบันทึก
   - การ์ดสรุปภาพรวมพร้อมวิเคราะห์ทิศทางและอัตราการเปลี่ยนแปลงอัตโนมัติ
   - การ์ดมาตรการติดตามเฝ้าระวัง 3 ข้อหลัก พร้อมช่องบันทึกข้อสั่งการเสริมประจำวัน
2. **ตัวกรองแบบยืดหยุ่น:**
   - เมนูเลือกวันที่ (ดึงจากคอลัมน์ C2 เป็นต้นไปใน Sheet)
   - เมนูเลือกช่วงเวลา (เวลาเริ่มต้น - เวลาสิ้นสุด) และปุ่มลัดกะการทำงาน (กะเช้า, กะบ่าย, กะดึก, 24 ชม.)
   - สลับดูหน่วย `%` (ระดับความสูง %) และ `m` (ระดับความสูงเมตร)
3. **การส่งออกรายงาน:**
   - รองรับการกดปุ่ม "พิมพ์" เพื่อพิมพ์เอกสารหรือบันทึกเป็นไฟล์ PDF ตามมาตรฐานรายงาน
